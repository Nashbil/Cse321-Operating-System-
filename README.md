# KernelCraft: Exploring the Mechanics of Operating Systems

KernelCraft is a collection of Operating System experiments and implementations designed to explore how modern operating systems manage processes, memory, and system resources.

Instead of treating OS concepts as pure theory, this project focuses on **hands-on implementations** that demonstrate how operating systems actually function behind the scenes.

---

## Project Overview

Operating systems are the backbone of every computer system.  
They manage hardware resources, control processes, and provide the environment where applications run.

This repository contains implementations and experiments related to core operating system concepts to better understand how these mechanisms work internally.

---

## Topics Covered

- Process Management  
- CPU Scheduling Algorithms  
- Synchronization Concepts  
- Memory Management  
- Deadlock Concepts
